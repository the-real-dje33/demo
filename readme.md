# 🕹️ NEON NOSTALGIA // RETRO DEMO 1995

> A lightweight, zero-dependency 1990s style Demoscene experience built purely with Vanilla JavaScript, HTML5 Canvas, and the Web Audio API.

## 🌟 Overview

**NEON NOSTALGIA** brings back the golden age of the **Demoscene** (Assembly, Revision, Future Crew era) directly to your web browser.

The goal of this project is to showcase what can be achieved in real-time graphics and sound generation using **100% native Web technologies**—without using any external libraries, frameworks, or pre-rendered assets.

Everything you see and hear is generated on the fly:

* 🎨 **No Images / Textures** loaded.
* 🎵 **No MP3 / WAV Files** loaded.
* 📦 **Zero Dependencies** (No Three.js, Tone.js, React, or jQuery).

## ✨ Features

* **⚡ Real-Time 3D Vector Engine**: 3D Wireframe projection rendered from scratch (Torus, Cube, Octahedron) with glowing neon vector shaders.
* **🌌 3D Warp Starfield**: Perspective-correct particle engine with dynamic velocity controls.
* **🌀 Procedural Sine Plasma**: Low-level pixel manipulation creating authentic demoscene color-shifting plasma.
* **📜 Bouncing Sine Text Scroller**: Classic demoscene greetings banner moving along a sine wave over animated copper raster bars.
* **🎶 Real-Time Web Audio Synth**: 16-step chiptune sequencer playing basslines, arpeggios, lead synth, and generated noise percussion (kick/hi-hats) on the fly.
* **📺 Retro CRT Filter**: Scanlines, RGB shift, and vignette overlays simulating vintage CRT monitors.

## 🛠️ Built With

* **HTML5 Canvas API**: Pixel-level rendering and vector math.
* **Web Audio API**: Frequency generation, envelopes, white noise generation, and step sequencing.
* **CSS3**: CRT scanlines, CRT flickering, dynamic sizing, and UI overlays.

## 🕹️ Controls & Customization

Once the demo is running, you can use the bottom control panel to interact with the experience:

* **FX Toggle**: Switch between full Plasma background and Starfield mode.
* **3D Mesh Toggle**: Cycle between 3D Torus, Cube, and Octahedron models.
* **CRT Toggle**: Enable or disable the CRT scanline overlay.
* **Audio Toggle**: Mute/Unmute the real-time synth audio engine.
